# ApexAudio GamePacks

Official game adaptation packages for ApexAudio.

## Download

Visit the official download page:

https://gray-raven-star.github.io/ApexAudio-GamePacks/

## Releases

Each game package version has an independent GitHub Release.

Release tag format:

pack/<slug>/v<version>

Each release contains:

- .gpack
- .sha256

## Source

Package definitions and build tools:

https://github.com/gray-raven-star/ApexAudio

## Community Packages

Third-party packages are not included in the
official registry or official release pipeline.
